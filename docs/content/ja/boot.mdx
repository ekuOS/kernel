## 再起動の前に

- ディストリビューション標準カーネルと、動作確認済みの起動エントリを残します。ekuOS のエントリが新しいカーネルと対応する initramfs を参照しているか確認し、initramfs がなければディストリビューションのツールで生成します。
- 選んだ版に対応するユーザー空間のセキュリティポリシーを設定します。特に SELinux 版には、適切なポリシーと正しくラベル付けされたファイルシステムが必要です。
- カーネルイメージは UEFI Secure Boot 用に署名されていません。Secure Boot が有効な環境では、起動チェーンが信頼する鍵でイメージを署名してから起動してください。パッケージの OpenPGP 署名とは別です。
- モジュール署名を強制します。ディストリビューション固有の外部モジュールや DKMS は対象外で、ヘッダーとモジュール署名用の秘密鍵は配布しません。ルートファイルシステム、ストレージ、ネットワークで外部モジュールが必須か事前に確認してください。

## デバイスのファームウェアとサービス

カーネルには一般的な機器向けの署名付きドライバが含まれます。ファームウェアとユーザー空間のサービスは、切り替え前にディストリビューション側から導入してください。たとえば Wi-Fi・Bluetooth・GPU には Linux ファームウェア、Sound Open Firmware 対応のオーディオ DSP を搭載するノート PC には SOF ファームウェアと ALSA UCM プロファイルが必要です。Bluetooth には BlueZ なども必要です。Debian では必要なファームウェアが `non-free-firmware` にある場合があります。

## 起動後の確認

```sh
uname -r
cat /sys/kernel/security/lsm
cat /sys/kernel/security/lockdown
```

`-eku-aa` の場合は `apparmor`、`-eku-se` の場合は `selinux` が有効になっていることを確認します。lockdown は `[confidentiality]` と表示されます。ユーザー空間のポリシーは、使用中の版に応じて `aa-status` または `getenforce` で確認します。

## 標準カーネルへ戻す

起動できない場合や必須のハードウェアが動かない場合は、ブートメニューで以前の標準カーネルを選択します。`uname -r` で標準カーネルに戻ったことを確認してから、ekuOS の設定変更やアンインストールを行います。動作確認が済むまで切り戻し先を残してください。
